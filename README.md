# FurgenOS Version 1.0 (first ship)
My very own WebOS that replicates a desktop operating system, such as Windows or MacOS (though understandably less featureful).

AI Usage:
I used AI mainly to help with the troubleshooting process (Hackatime is a nightmare), and also used it to simplify some of the instructions in the guide, especially towards the end, and to get a tutorial for the random URL feature. 

Features:
- draggable windows
- closeable windows
- Ronaldo quotes (various quotes by Ronaldo at different times)
- the current time and date
- a random website button (click "Messing Around" to be redirected)
