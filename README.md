# FurgenOS Version 2.0 (Ship #2)
My very own WebOS that replicates a desktop operating system, taking bits and pieces from guides and other OS, (especially retro Windows). Visit here: https://furgenramen04.github.io/FurgenOS/

AI Usage:
I used AI mainly to help with the troubleshooting process (Hackatime is a nightmare), and also used it mainly for JS as I am still a beginner to coding. Most CSS and HTML were written by me.

Features:
- draggable windows
- closeable windows
- Ronaldo quotes (various quotes by Ronaldo at different times)
- the current time and date
- a random website button (click "Messing Around" to be redirected)
- a MacOS-style sliding puzzle game
- a calculator
- a calendar
- a traveller's log where users can leave messages **Do not abuse this feature**
- a notebook/journal
- snake game (he has no eyes yet his tongue guides him
- an interesting version of pong (might be the buggiest game known to mankind)
  please be aware that the bot doesn't quite understand football, it scores own goals and does some weird stuff. i encourage you to find a friend and play 2 player.
